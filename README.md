# Disable Bat

一个简单的Minecraft资源包，用于禁用蝙蝠的模型渲染和声音。

## 功能

- 完全移除蝙蝠的模型渲染及音效
- 兼容大多数Minecraft版本（1.6.1 - 26.2）

## 安装方法

1. 从[Releases](https://github.com/Junhaoer/disable-bat/releases)页面下载最新的资源包文件
2. 打开Minecraft，进入"选项" > "资源包" > "打开资源包文件夹"
3. 将下载的文件放入文件夹中
4. 在游戏中启用该资源包即可

## 注意事项

- 该资源包仅在本地端生效，服务器端的玩家需要各自安装
- **开启f3+b后依然会显示蝙蝠的碰撞箱！**
- 不会影响其他游戏音效或性能
- **由于资源包的技术限制，必须启用光影才能隐藏蝙蝠的影子，我只测试了Complementary，其他光影大家可以自行测试！**
- **由于旧版本的资源包技术限制，旧版本无法通过资源包禁用蝙蝠的音效！**
